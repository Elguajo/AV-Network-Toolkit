# Phase 06 — selected-interface passive mDNS contract

2026-10-31, Asia/Tashkent. ADR-023 authorizes 06-T01–06-T04 on main; base `f160ac0986af59c7cc4357021b8ca7fe942b63e0`. No live execution, push or phase acceptance implied. P05-R01 remains OPEN and release-blocking.

## Smallest supported implementation

Reuse .NET 8 sockets, NetworkInterface, TimeProvider, existing RelayCommand/MVVM and Fluent/Mica/Card/FooterBar/resources. No new package, service daemon, native elevated helper or storage format. Separate window and discovery-only models/services do not call apply, browser, project serialization, scanner or legacy storage. Optional Add-to-device is omitted: users can manually create a reviewed device in the existing editor. No untrusted TXT/URL interpretation.

Passive IPv4 multicast listener only, no DNS queries/responses/probes or application send API. Explicit NIC selection (GUID/index/MAC plus IPv4 address/prefix set) and explicit Start. IPv6 transport is unsupported; A and AAAA records advertised over IPv4 are displayed, with link-local IPv6 scoped to the selected index. No claim of complete enumeration, trust, resolution or reachability. A quiet link can show no results indefinitely. No automatic browser, firewall or NIC change. Multicast membership can itself cause Windows IGMP traffic; actual Start is a live action requiring the separate isolated test gate during development.

Windows 10 1803+ IFLIST is mandatory: enable an initially empty receive allowlist, add exactly the selected index, enable packet metadata before binding UDP Any:5353, join 224.0.0.251 using that index. Wildcard local endpoint is required for multicast reception; it is not an all-NIC receive scope. Independently reject packets with a different/unknown incoming index, destination other than 224.0.0.251, source port other than 5353, or truncated metadata/data. No fallback if options/bind/membership fail. No send interface is necessary because nothing sends. Bound socket buffer, one pending receive, dispose socket to leave membership/cancel receive. OS/driver behavior remains UNVERIFIED until lab capture.

Recheck exact NIC fingerprint before opening, immediately after opening and each second (including idle and flood); disconnect, identity/index/MAC/address/prefix change or query failure stops, disposes and marks results stale. No silent rebind or restart. Alias is display only. Start/Stop/refresh/close serialize at the UI owner; cancellation during Start prevents later activation; repeated Stop is safe, repeated Start is rejected. Closing disposes immediately; no per-packet Dispatcher posts. Background processing owns cache; UI polls at most once per second. A session expires after 10 minutes and requires another explicit Start. New session clears previous scope/cache.

## Untrusted packet/cache limits

Maximum datagram 9000 bytes, 128 total questions/resource records, 255 expanded name bytes, 16 backward compression pointers/name. Reject invalid/truncated/forward/cyclic pointers, extended labels, invalid UTF-8, controls and ambiguous dot/backslash labels; this conservative presentation subset may omit valid exotic DNS names. Accept standard responses without RCODE error; ignore ID/AA/TC/RD/RA/Z/AD/CD on reception per RFC6762 §18. Actual socket/envelope/RDATA truncation is rejected regardless of TC. Ignore TXT/unknown RRs after validating envelope. PTR/SRV/A/AAAA IN records only, local domain only. No decompression recursion, TCP retry, resolver, or packet logging.

Single cache bounded to 1024 records; new entries dropped at capacity, existing refreshes allowed. Maximum accepted TTL 4500 seconds; UI shows remaining capped TTL, not an authenticity assertion. Goodbye schedules existing record expiry in one second, cache-flush ages other old members of that RRset to one second, protects records seen within the last second and preserves same-packet members. Expired records are removed; while listening, a bounded 256-row recent service view retains stale rows up to 60 seconds and then drops them. A stopped session retains a bounded frozen snapshot until explicit restart/window close, always stale/TTL zero. Incomplete service rows remain visible; fields never derive from expired dependencies. Contradictory SRV data is incomplete rather than silently selecting a trusted target. Address presentation/export is capped at 16 per service and marks a capped row incomplete; the window states the limit. Up to 100 receives/second, enforced with cancellable delay before the next receive, including malformed/foreign packets; excess traffic is dropped by the bounded OS buffer. UI/export use bounded snapshots, never a packet event queue. Cache-limit drops and row caps are visible; partial observation is expected. Stable observable row identities retain selection/scroll position during TTL updates; status/scope and Stop remain in the fixed footer.

## Export and verification

Case-insensitive text filter covers instance/type/host/addresses. Export only the current filtered snapshot after an explicit Save CSV dialog and overwrite confirmation. Include scope, snapshot status, remaining TTL and untrusted/incomplete/stale state. RFC4180 quote every cell and double quotes; prefix apostrophe for formula triggers `= + - @` after leading whitespace/control, strip controls. No automatic files/logs/history; exports may contain private network observations and the dialog warns accordingly. Stopped results are stale and TTL zero; filter/selection/export never starts listening.

Tests inject socket factory/native socket operations, NIC source and clock; never construct a real socket, enumerate NICs or join groups. Verify actual production option ordering/payloads and receive metadata path with a fake socket boundary, plus parser/cache/flood/session/cancellation/expiry and WPF component states. Native driver, shared-port/firewall, IGMP/packet captures, full App/tray and manual accessibility remain NOT RUN. Local NetworkInterface enumeration is a synchronous OS call without a native abort contract: if it stalls, cancellation immediately disposes the published socket but worker completion/Stop await can be delayed. Native stalls, NIC changes between periodic checks and driver/index reuse races remain acceptance risks; no hard real-time safety guarantee is claimed.

## Primary sources consulted

- [RFC 6762](https://www.rfc-editor.org/rfc/rfc6762.html), especially 10, 14, 15, 18: multicast/source port, TTL/goodbye/cache-flush, per-link data and shared socket limitations. Passive observer is not a full querier/responder.
- [RFC 6763](https://www.rfc-editor.org/rfc/rfc6763.html): PTR service browsing and SRV host/port; no TXT-driven actions.
- [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html): packet lengths, RR envelopes and bounded name compression.
- [Microsoft IPPROTO_IP options](https://learn.microsoft.com/en-us/windows/win32/winsock/ipproto-ip-socket-options): mandatory IFLIST, explicit membership, PacketInformation and Windows 10 1803 minimum. Implementation interprets DWORD(IF_INDEX) as a native integer index; this is an API-type inference, unlike IP_MULTICAST_IF's documented network-address encoding. Exact driver behavior remains UNVERIFIED until isolated capture; no byte-order fallback is attempted.
- [Microsoft SDK constants](https://github.com/microsoft/win32metadata/blob/main/generation/WinSDK/RecompiledIdlHeaders/shared/ws2ipdef.h): IP_IFLIST=28, IP_ADD_IFLIST=29. Constants are API identifiers, no source/assets copied.
- [.NET ReceiveMessageFromAsync](https://learn.microsoft.com/en-us/dotnet/api/system.net.sockets.socket.receivemessagefromasync?view=net-8.0): cancellable memory overload and packet information; enable PacketInformation before bind. English web fetch unavailable; Microsoft localized API page and installed .NET8 compilation used. Native integration is not inferred from compilation.
