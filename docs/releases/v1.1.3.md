> **Release status: Preview.** Physical tray/mixed-DPI, native networking and clean-client acceptance remain incomplete.

This focused update to **1.1.2** makes adapter selection and tray shortcuts easier to use. Useful interfaces stay visible, system-list clutter is hidden by default, and the tray menu opens near the icon you clicked.

## ✨ Highlights

### Find the adapter you need

Confirmed system filters and idle built-in WAN/debug plumbing are hidden from the main and tray adapter lists. **Show all** restores the underlying list. Working, virtual, disconnected and unknown adapters, profiles, history and edit drafts are retained; no Windows interface is disabled or removed.

### Keep changes tied to the intended target

Refresh retains the selected adapter by GUID. If a selected target is hidden or removed, selection clears instead of silently choosing another interface.

## Fixes & improvements

- **Tray placement:** open the menu above the clicked icon, using its monitor's bounds, DPI conversion and edge clamping; existing actions/style are preserved.
- **Package diagnostics:** retain installer logs and named stage/exit codes to diagnose reinstall failures. The first 1.1.2 reinstall CI failure remains of unverified transient cause; the instrumented rerun passed.
- **Continuity:** includes 1.1.2's verified Apply/Revert, supported DNS journals, safe saves, recovery paging, migration retry, matching and theme fixes, plus .NET 10.
- **Scope clarity:** left-navigation research is planning only in this version. The icon rail and resizable sidebar arrive in 1.1.5.

## 🔄 Updating

1. Back up local profiles, settings, history, private recovery journals and project JSON files.
2. Use **Exit** in the tray menu before installing or replacing files. Closing the main window can leave the application running.
3. Run the installer, or replace the portable application with the complete extracted package.

**Your data:** profiles/settings/history remain in `%LOCALAPPDATA%\NetworkProfileManager\data`, recovery journals in `%LOCALAPPDATA%\NetworkProfileManager\apply-recovery`, and project JSON where you save it. Uninstall retains user data. Installer and ZIP share these per-user locations; portable does not mean USB-local settings. No home-folder migration is included. Keep backups and journals securely and manage their retention manually.

Project v1 and storage paths are unchanged. This release adds no password fields, schema migration or home-folder storage.

## Known limitations

- **Network operations:** explicitly select the intended adapter and review current/requested values. Complex/unknown/managed settings, multiple IPv4 addresses, static automatic DNS, /31–/32 and initial no-lease/APIPA states remain blocked by the shared local/project Apply contract; profiles remain editable. Empty DNS in local static input leaves DNS unchanged, while an empty gateway removes the supported default gateway after review. Project static-DNS profiles require valid explicit DNS.
- **Recovery:** newer history requires its exact valid, matching recovery journal; missing/mismatched journals block full recovery. Older history only offers its warned address/DHCP-policy restore. Recovery is separately confirmed, non-atomic and can fail. DHCP recovery restores policy, not the previous lease. Keep independent recovery.
- **Validation:** Real NIC/UAC/IPC/DAD, DNS/route recovery, ICMP/TCP/multicast, physical egress and driver/topology acceptance remain unverified. Source binding and route prediction do not prove actual physical egress; TCP acceptance does not validate HTTP/TLS. Hosted Windows Server package checks do not certify a pristine Windows client or historical cross-version upgrades. Physical mixed-DPI/Explorer/auto-hidden-taskbar placement and driver classification remain pending; unknown adapter metadata stays visible. Manual accessibility/high contrast and physical/USB/Wi-Fi/Hyper-V acceptance remain incomplete.
- **Diagnostic check:** this source still carries the recorded intermittent hide/cancel smoke failure (`Hidden diagnostic window continued sending`); its cause/product impact was unresolved for this version. Later passing fixtures do not close historical acceptance records or establish native cancellation.
- **Scope:** No temporary DHCP server, device-password storage, automatic device login, TLS bypass, automatic updater or USB-local data mode is shipped. Opening a project or selecting a device never applies network settings.

See the [exact compatibility/recovery matrix](https://github.com/Elguajo/AV-Network-Toolkit/blob/v1.1.3/docs/spec/AUDIT_FIXES_CONTRACT.md) and [adapter-classification evidence](https://github.com/Elguajo/AV-Network-Toolkit/blob/v1.1.3/docs/testing/ADAPTER_VISIBILITY_REVIEW.md).
