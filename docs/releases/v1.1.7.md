AV Network Toolkit 1.1.7 now includes a compact network-settings confirmation and fixes for expired approvals and misleading failure messages, alongside the profile-switching, device-editor, diagnostic-startup and unsaved-change improvements. Highlights below include the original changes relative to 1.1.6 and the corrected packages.

## Highlights

- **Clearer network confirmation:** compare the selected adapter's IP, mask, gateway and DNS in a compact dialog; unchanged values are labelled and technical details are optional. Disconnected/conflict warnings stay visible. Cancel starts focused; applying settings remains deliberate.
- **Expired confirmation handled safely:** if approval expires during preparation or while waiting for administrator permission before any network command, current settings are read again and a fresh confirmation is required. Partially executed or uncertain operations are never repeated automatically.
- **Accurate failure guidance:** a known no-change refusal no longer claims partial network changes. Permanent worker-exit blocking is distinguished from temporary busy/update states. A browser-only failure preserves the verified network result and suggests retrying Open; journal warnings remain visible.
- **Device editing:** separate Add/Edit dialog with required name/URL first, optional profile/password/details, fixed actions and many-device navigation with a selected-device details card. Opening or cancelling an editor does not save a file, open a device or apply settings.
- **Profile switching:** correct adapter-observation failures and support fully classified ordinary DHCP/APIPA-to-static transitions and saving configuration with the cable disconnected. Offline success explicitly means saved policy, pending reconnection; Apply & Open does not open a browser while disconnected.
- **Faster diagnostic startup:** basic adapter/source facts become available independently of the slower full inventory. Running tests keep their original adapter/source and require explicit Run.
- **Consistent confirmations:** unsaved-change confirmation follows the app's light/dark Fluent style. Cancel starts focused; Enter on opening, Escape and close preserve the draft. Discard changes requires a deliberate choice.

## Updating and your data

1. Back up project JSON, local data and recovery journals independently.
2. Exit the old instance through **tray → Exit**; closing the main window may leave it running.
3. Use the installer or extract the complete portable ZIP into a new folder, retaining the old version. Run as an ordinary user; elevation remains a separate deliberate action for network changes.
4. If upgrading from a pre-home-storage version, review the explicit migration/source/destination/backup consent before copying. Originals and snapshots are retained; there is no automatic merge or reverse synchronization with older builds.

**Passwords:** optional device passwords are plaintext in v2 project JSON and backups. Older builds cannot read v2; preserve the original v1 file. This release does not change the v1/v2 schema, add automatic login or bypass TLS.

**Recovery compatibility:** newer recovery journals can describe previously unsupported DNS/route/APIPA/offline states; older builds may reject them. DHCP recovery restores policy, not a historical lease/APIPA address. Do not infer complete rollback from retained history.

## Known limitations

- Complex/unknown/managed adapter states, multiple configured addresses, custom routes and unsupported static-DNS/prefix combinations remain blocked. Empty DNS preserves the reviewed policy/list; removing a gateway is an explicit reviewed change. Saved offline settings do not establish address usability or connectivity.
- A normal static profile after manual Link-Local can still be blocked; some invalid local/manual fields are rejected only at Apply, and a successful recovery can hide its final journal-write warning. These are open findings, not fixes in 1.1.7. [Exact findings and support contract](https://github.com/Elguajo/AV-Network-Toolkit/blob/v1.1.7/docs/testing/PROFILE_SWITCHING_AUDIT_2026-11-02.md).
- Real NIC/UAC/DAD/reconnect/recovery, actual packet egress/multicast, clipboard/history, Narrator/high contrast, physical 150%/200% and mixed-monitor DPI, pristine-client and historical cross-version upgrades remain unverified. No temporary DHCP server, USB-local mode or automatic update activation.
