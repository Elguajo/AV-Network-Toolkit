# AV Network Toolkit 1.1.1 — Preview

First release of the AV Network Toolkit fork, with the owner-supplied cyan/blue ribbon logo and new Windows application/installer icon. Upstream Network Profile Manager 1.1.1 history is retained separately in the changelog.

## Downloads

- **Installer:** `AVNetworkToolkit-1.1.1-win-x64-setup.exe` — primary option for regular use; Program Files installation, Start menu shortcut and uninstaller.
- **Portable:** `AVNetworkToolkit-1.1.1-win-x64-portable.zip` — extract the entire ZIP and start `NetworkProfileManager.exe`; keep the five WPF DLLs beside it.
- Both packages bundle the required .NET runtime. No separate .NET/SDK installation is needed. They contain the same application payload/version.
- `SHA256SUMS.txt` and `package-manifest.json` identify exact artifact checksums and source commit. Binaries are unsigned; only run downloads whose origin/integrity you trust.

## Changes in this fork

- New logo and multi-resolution Windows EXE/window/tray/installer icon.
- Independent project JSON, static/DHCP profiles, safe Open/Save/Save As, strict schema/semantic checks and project/device references.
- Device web-interface catalogue with exact deep links, safe HTTP/HTTPS opening, optional linked profiles and explicit Apply & Open.
- Main workspace with separate local/project profile sources, detached profile editor, explicit per-adapter apply and observed-current-profile display.
- Project apply verification and separately confirmed recovery, with conservative support gates, private recovery snapshots and no browser opening on failed/unverified apply.
- Manual Link-Local, selected-interface passive IPv4 mDNS, adapter/Hyper-V diagnostics and opt-in diagnostic uplink filtering.
- Ready-made four-request, continuous and single-request Ping, plus source-bound one-port TCP check; explicit adapter/source/destination, Run/Stop and separate window.
- Fixed concurrent project-schema evaluation that could accept invalid DHCP/IPv4 or static-DNS combinations; before/after failure and regression evidence retained.
- English UI supported; old Turkish preference falls back to English. Existing local profiles/scanner/history/tray/UAC capabilities preserved within their documented limits.
- Primary installer and additional self-contained ZIP, verified compiler pins, package host/WPF/JSON checks and hosted Windows installation/reinstallation/uninstall verification.

## Data and updating

Existing profiles/settings/history stay in `%LOCALAPPDATA%\NetworkProfileManager\data`. Private project recovery journals stay in `%LOCALAPPDATA%\NetworkProfileManager\apply-recovery`; user-chosen project JSON files stay where saved. Back them up before updating. Exit through the tray menu before installing/replacing files. Installer uninstall keeps user data; portable does not make settings USB-local. The approved future `%USERPROFILE%\.av-network-toolkit` migration is **not included**.

## Limitations

This is a **Preview**, not a claim that all development phases/native acceptance gates are complete. Unit/fake tests, actual WPF component captures and hosted runtime-discovery/package checks are recorded in the repository and release CI. Hosted Windows Server checks are not a pristine Windows 10/11 client or physical-network certification.

- Isolated real NIC apply/verification/recovery, real UAC/IPC/DAD, native multicast/driver/route/ICMP/TCP/egress and manual accessibility/high-contrast/scaling acceptance remain unverified. Only act on a deliberately selected adapter; retain independent recovery.
- Legacy history/revert does not capture every DNS/route/additional-address setting. Recovery is non-atomic and can fail; no automatic rollback guarantee.
- Unknown/complex/managed configurations, static automatic DNS, /31–/32 and initial no-lease/APIPA state remain blocked by the new apply flow. Source selection/route prediction do not prove physical egress or device health.
- Installer same-version reinstall/data retention is tested. True historical cross-version installer upgrades are not yet certified.
- Temporary DHCP server, portable device passwords, automatic login/TLS bypass, automatic updater and USB-local settings mode are not shipped.
