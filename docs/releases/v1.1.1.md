> **Release status: Preview.** Physical-network, recovery, clean-client installation and manual accessibility acceptance remain incomplete.

This is the first **AV Network Toolkit fork release**, extending Network Profile Manager for AV field work. Keep the laptop's network presets and equipment web links in one project, then deliberately choose when to change the selected adapter.

## ✨ Highlights

### Take an AV project between computers

Save static/DHCP profiles and device entries in an independent versioned JSON project. Open, Save and Save As keep project files separate from the existing per-adapter local profile store.

### Reach equipment through saved interfaces

Keep full HTTP/HTTPS device URLs, including ports, paths, queries and fragments, and associate a project profile where useful. Use Open for the link alone or **Apply & Open** to review, apply and verify supported settings first. Failed or unverified apply does not open the browser; unsafe schemes and embedded URL credentials are rejected.

### Diagnose from the same workspace

Choose four-request, continuous or single-request Ping, or check one TCP port, with an explicit adapter/source/destination and Run/Stop controls. Manual Link-Local, passive selected-interface IPv4 mDNS and Ethernet/Hyper-V facts complement the inherited scanner.

## Fixes & improvements

- **Project validation:** fixed concurrent schema evaluation that could accept invalid DHCP-with-IPv4 or static-DNS documents; regression evidence retains the original failures.
- **Workspace:** separate local/project profile sources, a detached editor, adapter-named Apply actions and a reported-current-profile indicator.
- **Existing functionality:** named local profiles, five per-adapter slots, IPv4/mask/gateway/primary and secondary DNS, JSON import/export, scanner, history/revert, tray and UAC are inherited and retained within their documented limits.
- **Identity:** new owner-supplied cyan/blue logo and Windows icons. English remains supported; a saved Turkish preference falls back to English.
- **Packaging:** installer and portable ZIP include the runtime, source manifest, checksums and required notices.

## 🔄 Updating

1. Back up local profiles, settings, history, private recovery journals and project JSON files.
2. Use **Exit** in the tray menu before installing or replacing files. Closing the main window can leave the application running.
3. Run the installer, or replace the portable application with the complete extracted package.

**Your data:** profiles/settings/history remain in `%LOCALAPPDATA%\NetworkProfileManager\data`, recovery journals in `%LOCALAPPDATA%\NetworkProfileManager\apply-recovery`, and project JSON where you save it. Uninstall retains user data. Installer and ZIP share these per-user locations; portable does not mean USB-local settings. No home-folder migration is included. Keep backups and journals securely and manage their retention manually.

Project JSON v1 has no password fields. New profile/device flows do not silently replace the legacy local store or change the network when a project opens.

## Known limitations

- **Network operations:** deliberate adapter selection and UAC remain required. The new project Apply flow blocks unknown/complex/managed configurations, static automatic DNS, /31–/32 and initial no-lease/APIPA states; this does not imply that inherited local mutation has the later 1.1.2 safety hardening.
- **Recovery:** legacy history does not snapshot all DNS/routes/additional addresses. Project recovery is separately confirmed, best effort, non-atomic and can fail; neither path guarantees complete rollback. Keep independent recovery.
- **Validation:** Real NIC/UAC/IPC/DAD, DNS/route recovery, ICMP/TCP/multicast, physical egress and driver/topology acceptance remain unverified. Source binding and route prediction do not prove actual physical egress; TCP acceptance does not validate HTTP/TLS. Hosted Windows Server package checks do not certify a pristine Windows client or historical cross-version upgrades. Manual accessibility, high contrast, scaling and physical/USB/Wi-Fi/Hyper-V acceptance remain pending. Same-version reinstall/data retention was tested, not every historical upgrade.
- **Scope:** No temporary DHCP server, device-password storage, automatic device login, TLS bypass, automatic updater or USB-local data mode is shipped. Opening a project or selecting a device never applies network settings. The later user-home migration and .NET 10 transition are not part of this version.
