Generic exceptions crossing the execution boundary remain conservative unknown/possibly changed, never blindly converted to no-change.

- **SWITCH-12:** BrowserFailed / BrowserHandoff keeps the verified-network and separate Open guidance. Both surfaces use the shared recovery-warning predicate; browser-only failure never gains the generic partial-network warning. An independent final-journal warning remains visible. Existing real partial/unknown failures retain explicit recovery guidance.
