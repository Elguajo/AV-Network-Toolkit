# С чего начать (для владельца проекта)

В архиве зафиксирован **план**, а не реализованная программа. Все 9 этапов разложены на задачи с ID и критериями приёмки. Для долгого проекта Codex должен читать эти файлы в каждом новом сеансе.

1. Создай fork `https://github.com/rmzncakir/network-profile-changer`.
2. Скопируй **содержимое** архива в корень форка, не удаляя исходники и `LICENSE`. Не добавляй сюда реальные IP-адреса и пароли клиентов.
3. Открой свой форк в Codex.
4. Отправь агенту текст `prompts/CODEX_BOOTSTRAP.md`.
5. Получи отчёт **первого, только исследовательского** этапа. После его проверки отдельно разрешай этап 02.
6. Для каждого нового чата с Codex используй `prompts/CODEX_RESUME.md`.

Основной источник контекста: `AGENTS.md` + `PROJECT_CONTEXT.md` + `STATUS.md` + `TASKS.md` + текущий `phases/NN-*.md`.

**Текущее состояние (2026-10-31):** fork подключён, read-only аудит записан; см. `STATUS.md`. Попытка сборки остановилась до компиляции из-за отсутствия SDK; unit/live tests не запускались. Разрешено внесение результатов в документацию и локальный commit, но не начало Phase 02 и не исправления кода. Шаги выше описывают первоначальный запуск; для продолжения используй `prompts/CODEX_RESUME.md`. Лицензия AV Network Toolbag не найдена в проверенном дереве; исходники и ресурсы не копировать.
